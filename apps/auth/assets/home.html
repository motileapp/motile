A command center for your coding agents

Run Claude Code and Codex on machines you own, and drive them from a native app. Your threads keep working when you close the lid.

Download for macOS View the source

Apple silicon, macOS 14 or later. Open source under the MIT license.

1 Sign in

Open the app and sign in with Google. Motile's server only keeps track of which devices are yours.

2 Add a host

The app shows one command. Run it on a Linux machine and that machine appears in the app.

curl -fsSL https://motile.app/install | sh -s -- …
3 Start a thread

Pick a folder on the host and ask. The app talks straight to your machine, encrypted end to end.
